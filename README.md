# tgbotrecord
📅 Telegram-бот для записи клиентов
Этот бот помогает автоматизировать процесс записи клиентов для офиса и среднего бизнеса. С его помощью пользователи смогут:

Забронируйте удобное время для записи.
Посмотреть доступные слоты.
Получите информацию о предстоящих визитах.
Адаптация для салонов красоты, медицинских клиник, фитнес-центров и других услуг с предварительной записью.

💡 Особенности:

Простота настройки.
Удобный интерфейс для клиентов.
Вы сами можете выставлять для себя интервал работы, любые даты и любое время.

📂 Исходный код:
Разработчики могут легко настроить бота под свои нужды или внести изменения в его функционал.

👨‍💻 Готово к развертыванию — просто скачайте и начните пользоваться!

Чтобы начать пользоваться достаточно просто в код вставить токен бота(в строке 4) и добавить айди администратора(в строке 7)

Также можете настроить его под свои нужды! 

Команда /i_am_cyborg покажет команды для функционала администратора
